# Trading lab

Приватная лаборатория виртуальной торговли Bybit. Реальных ордеров нет.

## Исходники

`src/` — 21 файл исходников с сервера NODE-02, полученный 1 октября 2026 года.
`deploy/` — 11 существующих описаний systemd. Импорт сохранён отдельным коммитом.
Рабочие балансы, истории, базы и секреты не включены.

**Неполнота архива:** панель обращается к `/api/signals`, но серверный компонент
`/opt/trading-signals` и его systemd unit не были включены в экспорт.
Это не мешает автономным тестам, но полный перенос на новый сервер пока невозможен.

## Проверки

Python 3.12 и Node.js 22:

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements-dev.txt
python tools/check.py
```

Проверяются синтаксис Python/JavaScript, 13 тестов модели B, 6 тестов отчётов,
самопроверки модели A и LIVE. Сетевые службы и торговые циклы не запускаются.
GitHub Actions выполняет те же проверки при push и pull request.

## Просмотр интерфейса

```sh
python tools/preview.py
```

Открыть http://127.0.0.1:8788. Данные полностью синтетические, обновляются при запросе.
Панель получает демонстрационные сделки и пустые рыночные списки. Это проверка
отображения, а не бэктест. Рабочие `/opt` и `/var/lib` не читаются и не изменяются.
Для проверки с настоящими данными нужен отдельный обезличенный набор снимков.

## Обновления

Эта ветка ещё не является установщиком. Не копируйте весь `src/` поверх сервера
и не перезапускайте модели с открытой позицией. Обновление одной командой с
проверкой исходной версии, резервированием и откатом будет отдельным изменением.
Основной код моделей в этом импорте не изменён.
