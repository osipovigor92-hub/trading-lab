# Trading lab

Приватная лаборатория виртуальной торговли Bybit. Реальных ордеров нет.

## Исходники

`src/` — 22 файла исходников с сервера NODE-02, полученный 1 октября 2026 года.
`deploy/` — 12 существующих описаний systemd. Импорт сохранён отдельным коммитом.
Рабочие балансы, истории, базы и секреты не включены.

Компонент `trading-signals` добавлен из второго архива.

## Проверки

Python 3.12 и Node.js 22:

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements-dev.txt
python tools/check.py
```

Проверяются синтаксис Python/JavaScript, 13 тестов модели B, 6 тестов отчётов,
самопроверки модели A, LIVE и signals. Сетевые службы и торговые циклы не запускаются.
GitHub Actions выполняет те же проверки при push и pull request.

## Просмотр интерфейса

```sh
python tools/preview.py
```

Открыть http://127.0.0.1:8788. Данные полностью синтетические, обновляются при запросе.
Панель получает демонстрационные сделки и пустые рыночные списки. Это проверка
отображения, а не бэктест. Рабочие `/opt` и `/var/lib` не читаются и не изменяются.
Для проверки с настоящими данными нужен отдельный обезличенный набор снимков.

## Обновления

См. [порядок обновления](docs/deployment.md). `tools/update.sh` принимает полный
SHA проверенного коммита. `tools/deploy.py` сверяет исходную версию, делает резервную
копию и автоматически восстанавливает исходники при ошибке.

Первая версия обновлятора поддерживает панель, отчёты и `trading-signals`.
Изменения моделей, LIVE и systemd units блокируются. Первичная регистрация текущего
экспорта не перезапускает службы. Обновлятор предназначен для существующего NODE-02,
а не для установки на пустой сервер.
