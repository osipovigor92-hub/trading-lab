# Общее избранное ПК и телефона

Панель сохраняет три существующих списка избранного на своём сервере:
скринер Bybit (8 монет), биржевые графики (24 пары) и плотности (20 пар).
Это общие настройки одной установки панели, без разделения по пользователям.

После установки откройте панель на ПК в прежнем браузере и по прежнему адресу.
Дождитесь сообщения «Избранное синхронизировано», затем обновите телефон.
Не очищайте данные браузера ПК до переноса: исходное избранное находится там.
Пустой телефон не удаляет монеты на сервере. При первом посещении списки
объединяются; при превышении существующих лимитов показана ошибка без обрезания.

GET /api/favorites возвращает группы и существующий токен панели. POST использует
проверку токена и источника control_client.authorized и принимает только отдельные
добавления/удаления, максимум 104 операции и 16 KiB. Изменение торгового счёта или
позиций через этот API невозможно. Повтор последних 256 идентификаторов команд
не применяет изменение второй раз. Одновременные изменения разных монет
сохраняются; для одной монеты действует последняя принятая операция.

Файл /var/lib/trading-manual-paper/favorites.json записывается атомарно под
блокировкой, отдельно от счёта PAPER. Каталог уже создаётся install_manual.py.
Повреждённый файл не перезаписывается автоматически. Ошибки диска отображаются
в интерфейсе; очередь браузера повторяет запрос после восстановления связи.
Опрос каждые 5 секунд обновляет локальный кэш и существующие списки без
перезагрузки страницы. Очередь и отметка миграции хранятся в localStorage.

Проверки: test_favorites.py, test_manual_http.py и test_favorites_ui.cjs.
Последний запускает два независимых браузерных контекста ПК и телефона,
проверяет импорт трёх списков, добавление/удаление, перезагрузку и обрыв связи.
