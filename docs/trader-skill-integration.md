Это пакет из 11 навыков Claude для американских акций, а не движок Bybit.
В Trading Lab адаптированы правила trader-budget и trader-risk. Это отдельная
криптовалютная реализация, не запуск исходного Alpaca check.py: исходник
отклоняет USDT-символы. Внешние зависимости, фоновые процессы и брокерские
ключи не добавлены. Лицензия сохранена в docs/licenses/trader-skill-MIT.txt
и в развёртываемом модуле trader_risk.py.

## Что работает в панели

Скринер → таблица → монета → «Калькулятор риска»: резерв бюджета (%), предел
позиции (%), минимальный вход (USDT). Для новых планов начальные значения
10 / 25 / 5 взяты из исходного примера; пользователь может менять их до
подготовки плана. Предел 100 USDT на ручной вход сохраняется. Эти правила
показываются в подтверждении на вкладке «Позиции». Это не настройки моделей A–D.

Сервер считает доступный капитал как минимум введённого капитала и текущего
PAPER-баланса. Резерв исключается из доступных средств; максимальный номинал
ограничен долей этого капитала и существующим абсолютным лимитом. В резерв
исполнения входят номинал и комиссия входа. LONG и SHORT резервируют полный
номинал, как и раньше: кредитное плечо не добавляется. Размер также ограничен
риском до стопа и существующими проверками стакана, funding и издержек.
Если итоговый размер меньше минимального, вход отклоняется, не увеличивается.

Перед сохранением позиции сервер проверяет фактический рассчитанный размер.
В позицию и затем журнал сделки записываются версия проверки, PASS, время,
лимиты, объём, комиссия и SHA-256 конкретного плана/баланса/исполнения. PASS
не разрешает автоматическое открытие: остаётся ручное подтверждение в панели.
Fingerprint — аудит, не подпись и не токен авторизации. Идемпотентность команд,
проверка поколения состояния и транзакции SQLite остаются действующими.

Старые планы без дополнительных полей используют резерв 0%, долю 100%,
минимум 0 и прежние абсолютные ограничения. Открытые позиции не пересчитываются.
PAPER баланс отражает существующий учёт PnL; cash_after_reservation в проверке —
расчёт доступных денег после условного резервирования полного номинала.

## Остальные модули исходного пакета

- copycat / analyst / screener: SEC 13F, XBRL и фундаментальный отбор акций.
- news / pelosi: новости акций и раскрытия Конгресса США.
- alerts: цены Yahoo и календарь NYSE; не используется для круглосуточного Bybit.
- broker: формирует билет Alpaca; в эту интеграцию не подключён.
- tax / rebalance: налоговые лоты, wash-sale и веса портфеля акций.

Эти девять модулей не установлены в панель и не заменяют существующий криптоанализ.
Оригинальный набор можно отдельно установить в Claude Code по README upstream;
эта интеграция не меняет настройки локального Claude Code пользователя.

## Проверка и доставка

`python3 tools/check.py`; `node tools/test_assistant_ui.cjs`.
Обновление обычным tools/update.sh доставляет модуль с trading-panel и
перезапускает только изменённый сервис; миграция базы данных не требуется.
